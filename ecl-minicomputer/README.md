# ecl-minicomputer

Design exploration for a minicomputer built from ECL logic and aimed at raw
number-crunching speed. It is to be a load/store RISC with hardwired control
and no microcode. It's a sibling of [ttl-minicomputer](../ttl-minicomputer)
and borrows that project's ideas and way of working.

**Status: before draft 0.** Nothing is decided yet.
[docs/design-notes.md](docs/design-notes.md) has the first round of thinking:
what ECL changes, what the brief pushes towards, a strawman, rough chip
counts and the open questions.

There's nothing to run yet.
