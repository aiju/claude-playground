# Performance of draft 0

Generated by `python3 -m emc report`; don't edit by hand. The programs and
what they do are in [programs/](../programs), the pipeline presets in
[emc/pipeline.py](../emc/pipeline.py), and the hardware in
[hardware-v0.md](hardware-v0.md).

`p5` is the draft 0 hardware: 5 stages, BTFN prediction in ID, branch and JALR redirects from a register after EX (3 bubbles), 18-cycle multiply, 34-cycle divide, SLT results after MEM.
Its cycle counts are exact: the chip-level netlist runs every program in
the same number of cycles (`python3 -m emc hw run NAME`).

- `p5-nopredict`: as p5, but every branch predicted not taken.
- `p5-perfect`: as p5 with a perfect branch predictor and target buffer.
- `p5-resolve-ex`: as p5, branches redirect fetch from EX (one bubble fewer per mispredict and JALR; needs a slower clock).
- `p6-mem2`: memory access over two stages: one more load-use bubble.
- `p5-mul4`: as p5 with a 4-cycle multiply.
- `p5-mul8`: as p5 with an 8-cycle multiply (radix 16).
- `p5-sltfast`: as p5 with SLT results forwarded from EX like other ALU results.
- `p5-mulpipe`: as p5 with a pipelined 3-cycle multiplier.
- `brief`: the model the benchmark programs were tuned for (docs/notes-v0): 8-cycle multiply, branch and JALR redirects from EX (2 bubbles), SLT forwarded from EX.
